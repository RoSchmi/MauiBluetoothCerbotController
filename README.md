# MauiBluetoothCerbotController

This App serves to control the GHI FEZ-Cerbot from a Maui App.
https://docs.ghielectronics.com/hardware/gadgeteer/fez-cerbot.html
The App controls the motors to steer the Cerbot and can play some tunes. 
Actually in this Repo there is only a Windows version.

A version for iOS-Devices ist available in my fork of Laerdal/Plugin.Bluetooth in the branch: cerbotcontroller.
https://github.com/RoSchmi/Plugin.Bluetooth/tree/cerbotcontroller

On the PC the ORICO BTA-403 Dongle is used.
On the FEZ.Cerbot Justin's Bluetooth SMART Gadgeteer Modul is ussed.
The code on the Cerbot to receive the commands via Bluetooth is a NETMF 4.3 2026 R1 Gadgeteer Application
It can be found in this Repo: 

https://github.com/RoSchmi/NETMFGadgeteer
