# MauiBluetoothCerbotController
This App serves to control the GHI FEZ-Robot from a Maui App.
The App (when comleted) will control the motors an play some tunes (already working)
Actually only the Windows version is in work.
On the PC the ORICO BTA-403 Dongle is used.
On the FEZ.Cerbot is Justin's Bluetooth SMART Gadgeteer Modul.
The code on the Cerbot is a NETMF 4.3 Gadgeteer Application (will be available on GitHub later)
